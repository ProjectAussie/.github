# .github

Org-wide defaults for ProjectAussie repositories. Files here apply to any
repository in the org that does not carry its own copy:

- `PULL_REQUEST_TEMPLATE.md` -- default pull request template.

A repository that wants something different adds its own file, which always
wins over the default.

## This repository is public

GitHub only serves org-wide defaults from a public repository, so everything
here is world-readable. Nothing confidential may ever be committed: no
internal URLs, ticket references, team or system names, credentials, or
anything else that describes how things work internally. Keep every file
generic enough that publishing it costs nothing.
